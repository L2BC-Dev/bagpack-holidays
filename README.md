# Bagpack Holidays — website

Static multi-page site for Bagpack Holidays (Faridabad): Home, Services, Destinations, Visa, About, Contact.

- Plain HTML/CSS/JS, no build tools needed to host.
- Shared header/footer and page content live in `build.py`. Edit it, then run `python build.py` to regenerate all pages.
- Styles: `assets/css/style.css` · Behaviour (menu, filters, WhatsApp forms): `assets/js/main.js`
- Enquiry forms open WhatsApp (+91 92060 60645) with the details pre-filled.

Preview locally: `python -m http.server 5510` then open http://localhost:5510
